## Technical reports

For a useful technical report, include:

- ZTM version: `ZTM-SRP1V1`;
- Ubuntu version;
- CPU model;
- whether the 24-hour benchmark completed;
- selected thread profile if available;
- accepted/rejected shares if relevant;
- reproduction steps;
- sanitized log excerpts.

Do not include recovery seeds, wallet passwords, private keys, access tokens, administrator passwords or other credentials.

For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).

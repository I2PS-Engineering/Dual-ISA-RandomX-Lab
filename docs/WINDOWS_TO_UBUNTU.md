# Windows to Ubuntu — migration path

This path is for owners of Windows computers who want to move to Linux for I2PS RandomX Lab.

## Before installing

1. Back up documents and any wallet recovery material **offline**. Never submit a seed or private key to I2PS.
2. Check that the machine is yours or that you have permission to replace its operating system.
3. Download Ubuntu Desktop from the official website: https://ubuntu.com/download/desktop
4. Create an installation USB using a trusted flashing tool and follow Ubuntu's official installation instructions: https://ubuntu.com/tutorials/install-ubuntu-desktop
5. Boot the installation USB and verify the target drive **before** confirming changes. An erase-disk option destroys the previous Windows installation and data.
6. Complete Ubuntu installation and system updates.

## Continue with I2PS setup

Once Linux is installed, follow [Existing Linux users](EXISTING_LINUX.md) for the I2PS environment and, when available, the official v0.4 first-run Setup Assistant.

**Important:** Windows 11 unsupported-hardware checks and bypass demonstrations are a **separate educational episode**. Installing Ubuntu does not require attempting a Windows 11 bypass.

**Current release status:** The v0.4 guided auto-setup and 24-hour online engine are not yet shipped.

# Development roadmap

**Stage 0 — Documentation and public repository:** publish accurate product description, current status, copyright and third-party notices. **Complete for core documents.**

**Stage 1 — Installer:** reproducible first-run checks, pinned official XMRig builds, audit of Linux/Windows/macOS paths; no existing miner configuration changes.

**Stage 2 — Online-only benchmark engine:** remove the offline choice from the intended v0.4 interface and build a real pool-connected RandomX session with explicit consent and fixed Dev Wallet payout for the initial test.

**Stage 3 — Continuous 24-hour controller:** safe lifecycle management, interruption detection, run logs, failure restart policy, durable measured telemetry and user Stop.

**Stage 4 — Profile experiments and reporting:** systematic per-machine thread sweeps, stabilized measurement intervals, statistically defensible best-tested recommendations, exports with public-safe fields.

**Stage 5 — Post-benchmark wallet education:** official Monero links; public receiving address only; private key/seed warnings.

**Stage 6 — Personal mining and Dev Donate:** user wallet, explicit mining Start/Stop, define rate and developer-share mechanism transparently, independently preserve XMRig developer donation.

**Stage 7 — Compliance and release:** reconcile PolyForm Strict with intended monetized mining; verify GPLv3/XMRig obligations, CPU/power disclosures, real device trials, and build release artifacts.

**Stage 8 — Media and public guides:** record separate Windows-to-Linux and existing-Linux tutorials; publish only real reproducible screenshots and test data labeled by origin.

No dates or availability guarantees have been committed for these stages.

# YouTube filming plan — Zero to Monero, Part 2

**I2PS Engineering / Dual-ISA RandomX Lab**

## Episode A — Migrating from Windows to Ubuntu

1. Clean and prepare the server room; set camera, good lighting, clear labels and a readable screen-capture feed.
2. Briefly show the current Windows installation and the hardware compatibility check.
3. Explain that Windows 11 unsupported-hardware workarounds are a separate video topic.
4. Back up data and install Ubuntu from official media, being explicit about disk selection and possible data loss.
5. Update Ubuntu, open I2PS, run the installation process and discuss verified XMRig download.
6. Show the approved authorization screen and explain the future online-only 24-hour workflow.
7. Do not film or label simulated/demo stats as real hardware results.

## Episode B — Already using Linux

1. Start with an existing Linux machine — **do not reinstall its OS**.
2. Explain the current Ubuntu/Debian x86-64 target and show `bash install_i2ps_linux.sh --plan`.
3. Demonstrate `bash install_i2ps_linux.sh` on a safe test system.
4. Show the existing license gate, setup verification and local browser dashboard.
5. Explain what the v0.4 workflow will do when implemented (online 24 hours, Dev Wallet, personal wallet afterward).
6. Once real v0.4 testing succeeds, record actual long-duration measurements with full provenance and displayed Stop control.

## Recording equipment checklist

- At least two cameras or one camera plus high-resolution screen recording
- Tripod, soft lighting, clean background, microphone and audio monitoring
- USB installer, power/network connections, spare storage for backups
- Clean test machines with hardware labels that do not expose private identities
- Timestamped benchmark logs and clearly separated screen captures
- Verify no private IPs, account passwords, wallet seeds, or login tokens are visible

**Production rule:** Do not announce or demonstrate a v0.4 feature as working until it is genuinely implemented and tested.

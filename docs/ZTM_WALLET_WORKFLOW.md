# ZTM-SRP1V1 wallet workflow

Wallet and personal mining are gated until a qualifying 24-hour benchmark completes.

## Existing wallet

Use wallet software to copy the **public Monero receiving address** into ZTM.

ZTM does not require:

- wallet password;
- recovery seed;
- private spend key;
- private view key.

## Need a wallet?

Use official wallet software and follow its own creation/recovery instructions.

Official Monero resources:

https://www.getmonero.org/downloads/

https://www.getmonero.org/resources/user-guides/

Back up recovery information securely and offline.

## Personal mining

After ZTM accepts the public address and the machine has a qualifying benchmark result, the personal-mining workflow uses the tested CPU configuration.

The user's public receiving address is used for the user's payout path.

ZTM does not become a custodian of the wallet and cannot restore lost wallet secrets.

## Publication rules

- Keep exact official logo proportions; do not substitute generated logos.
- Use navy/cyan visual identity and thin cyan screenshot borders.
- For real GUI screenshots, use reproducible browser captures; do not call generated concept illustrations “actual screenshots”.
- Clearly label simulated benchmark data, if used in any example.
- Never publish personal wallets, private keys, seed phrases, machine hostnames/IPs or internal configurations.
